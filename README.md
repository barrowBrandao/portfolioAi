# Portfólio AI Builder — Carlos Brandão

Site estático (um único arquivo `index.html`) com projetos de IA, automação e dados construídos na Caju: Cajuíno, IA de suporte, Piloto de acompanhamento de ferramentas, canal de indicação de clientes, programa mensal de IA e agente de CRM pós-reunião.

## Como ver

Abra `index.html` no navegador ou publique com GitHub Pages (Settings > Pages > Deploy from a branch > `main` / root).

## Observações

- O dashboard do Piloto usa dados fictícios, identificados na página.
- As conversas de Slack e o formulário são ilustrações com conteúdo de exemplo.
